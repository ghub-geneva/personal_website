Casino App - Reports
Overview

The Reports module lives inside the Casino App at the /reports route. It generates 8 specialized report types from the uploaded casino data, all printable and exportable.

Report Types
  • Daily Server Report - Server hours, payouts, and customer counts by day
  • Revenue Summary - MTD gross, net, and projections per branch
  • Machine Performance - Cash in, amount played, and payout ratios per machine
  • Branch Comparison - Side-by-side metrics across all three branches
  • Cash Variance Report - Daily cash short/over analysis and running totals
  • Customer Activity - People count by server, day, and week
  • Server Leaderboard - Servers ranked by net revenue and efficiency
  • Payout Risk Report - Days with unusually high payout ratios flagged by risk level

HR App - LGU Cordova
Overview

Full-stack HR Employee Records System for LGU Cordova's Human Resource Management Office. Manages personnel records, employment history, and government-mandated documentation. Deployed to Vercel with a daily keepalive cron job and comprehensive HTTP security headers.

  • DTR Generator sub-page for Daily Time Records (see separate entry)

HR App - DTR Generator
Overview

A standalone Daily Time Record (DTR) generator at hr.genevadaugdaug.com/generate-dtr. Used by LGU Cordova HRMO staff to generate properly formatted DTR sheets that comply with Civil Service Commission (CSC) requirements, then export to Excel.

Features
  • Input employee name, position, and monthly schedule
  • Auto-calculates total hours rendered from time-in/out entries
  • Generates DTR in the official CSC-prescribed format
  • Exports to .xlsx with proper cell formatting, borders, and header layout
  • Part of the HR App - accessible from the main HR navigation
