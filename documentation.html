Animation Behavior

Skill bars start at width: 0 and animate to their target width when the section scrolls into view (30% threshold). Each bar animates in with a 120ms stagger using setTimeout. A glowing tip at the end of each bar pulses via @keyframes skill-shine.

Glassmorphism Cards

Cards use backdrop-filter: blur(12px), a semi-transparent white background (rgba(255,255,255,0.04)), and a subtle white border. They're supported in all modern browsers (Chrome 76+, Safari 9+, Firefox 103+).

⚠️ Firefox note: backdrop-filter requires enabling layout.css.backdrop-filter.enabled in older Firefox versions. All modern Firefox (103+) supports it natively.

Tags / Badges

Rounded pill tags inside service cards use rgba(109,40,217,0.12) background with a subtle purple border. Size: 0.67rem, weight 700.

Social Pills

Inline SVG icons with text, glass background, and hover border-color transition to purple. Used in both the hero and footer.

Customization Guide

All content and design tokens live inside index.html. Here's where to look for common changes.

Changing Colors

Edit the :root CSS variables at the top of the <style> block:

CSS :root variables
:root {
  --purple-1: #6d28d9;   /* darkest purple */
  --purple-2: #8b5cf6;   /* main accent */
  --purple-3: #a78bfa;   /* light accent */
  --purple-4: #c4b5fd;   /* lightest / text highlight */
}

Updating Profile Photo

Find the <img> tag inside .portrait-img and replace the src:

HTML
<img src="YOUR_PHOTO_URL_HERE" alt="Geneva Daugdaug" />

Updating Social Links

Search for the three .social-pill anchor tags and update the href values for LinkedIn, YouTube, and Upwork.

Adding a New Service Card

Duplicate an existing .service-card div inside #services and update the icon, title, description, and tags. The CSS grid will automatically reflow.

Updating Skill Percentages

Each skill bar has a data-width attribute: change the number to update both the bar and the displayed percentage:

HTML
<span class="skill-pct">98%</span>
<div class="skill-fill" data-width="98"></div>
💡 After making changes, run vercel --yes from the project folder to push the updated site to production instantly.
